# 📧 Spam Email Detection System

Machine Learning based web application that classifies emails/messages as **Spam** or **Not Spam** using Python and Streamlit.

## 🚀 Features
- Real-time spam prediction
- Streamlit web interface
- TF-IDF vectorization
- Naive Bayes classifier

## 🛠 Technologies Used
- Python
- Pandas
- Scikit-learn
- Streamlit

## ▶️ Run Locally
```bash
pip install -r requirements.txt
streamlit run app.py
```
